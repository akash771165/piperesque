## WRITING GUIDELINES

### Tone
- Professional but conversational
- Empathetic to homeowner problems
- Houston-focused
- Urgent where appropriate
- No AI fluff or generic content

### Technical SEO
- One H1 per page ONLY
- Title tags ≤ 60 characters
- Meta descriptions 140-160 characters
- Primary keyword in first 100 words
- Internal links: 5-10 per page
- External links: 0-3 (quality only)

### CRO Elements
- Phone number visible above fold
- "Request Free Estimate" CTA every 400-600 words
- "Call Now" buttons on mobile
- Emergency banner on every page
- Trust badges visible

### Local SEO
- Mention Houston neighborhoods
- Reference Houston climate/soil
- Local zip codes
- Local testimonials
- Houston-specific problems/solutions

### Structure
- Use H2/H3 subheadings (NO H1s except page title)
- Bold key points
- Use bullet lists for lists
- Use numbered lists for steps
- Short paragraphs (2-3 sentences max)
- White space for readability

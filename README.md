# Piperesque — Houston Emergency Plumbing Lead-Gen

Minimal production Next.js site to generate emergency plumbing leads in Houston. Focused on speed, SEO, and driving phone calls.

Quick start

1. Install dependencies

```bash
npm install
```

2. Build

```bash
npm run build
```

3. Start

```bash
npm start
```

Production notes

- Ensure environment variables (e.g., NEXT_PUBLIC_PHONE) are set for the production phone number.
- Static assets live in the `public/` directory.
